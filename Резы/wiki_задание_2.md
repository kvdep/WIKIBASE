# Задание 2

`задание_2.ipynb` содержит 12 вопросов к базе знаний об экосистеме PyTorch, эталонные ответы и результаты их проверки. Отчёт для сдачи находится в `Отчёт_задание_2.docx`.

## Запуск

Откройте ноутбук в Jupyter из каталога `Резы` и выберите ядро Python из корневой `.venv` проекта FU. Выполните все ячейки. Для запросов требуется `rdflib`; для запуска ноутбука нужны Jupyter и `ipykernel`.

- `run(query)` выполняет SPARQL-запрос к локальному `knowledge_graph.ttl`, печатает заголовки и строки, возвращает строки результата. Например, `run("SELECT ?s WHERE { ?s a ?type } LIMIT 1")` выводит один субъект графа.
- `check_quote(qid, quote)` проверяет, что цитата содержится в записи `data/corpus.jsonl` с указанным QID после нормализации пробелов. Вызовы с проверенными цитатами приведены в ячейках вопросов 7–10 и 12.

Ячейки читают граф и корпус без записи в эти файлы и работают без сети. В вопросе 11 граф возвращает QID библиотеки timm и по нему находится запись корпуса. Список моделей сверён с полным README по ссылке в вопросе, поскольку в сохранённый фрагмент эта часть не вошла.

## Обновление

При смене снимка данных повторно выполните запросы, сверяйте эталоны с полным результатом и пересмотрите ссылки на цитаты. Для комбинированных вопросов проверяйте единственность найденной записи и сопоставляйте её с корпусом по QID из `owl:sameAs`. Обновляйте формулировки и ответы в ноутбуке и DOCX вместе.
